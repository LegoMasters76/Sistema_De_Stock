## Acceso

1. Abra [URL del sistema] en un navegador actualizado.
2. Ingrese el usuario y la contraseña entregados por el administrador.
3. Para finalizar, cierre la sesión desde [ubicación del control de cierre de sesión].

No comparta credenciales. Solicite al administrador que desactive las cuentas de personas que ya no deban ingresar.

## Tareas habituales

### Consultar el inventario

1. Abra la sección [Stock/Inventario].
2. Busque por [campos de búsqueda disponibles] y revise cantidad, precio, categoría y proveedor.
3. Si la información no coincide con el inventario físico, registre un ajuste según el procedimiento interno antes de continuar con una venta.

### Mantener productos, categorías y proveedores

1. Abra [sección correspondiente].
2. Use [Agregar/Editar] para registrar o corregir los datos solicitados.
3. Revise los valores y confirme con [acción de guardado].
4. Antes de eliminar un registro, compruebe que no sea necesario para el historial de ventas o movimientos.

### Registrar una venta

1. Abra [Ventas] y seleccione o registre el cliente.
2. Agregue los productos y cantidades.
3. Revise el detalle y el total antes de confirmar.
4. Verifique que la venta aparezca en [historial/consulta de ventas] y que el stock se haya actualizado.

## Buenas prácticas y resolución inicial

- Verifique cantidades, precios y cliente antes de confirmar una operación.
- No registre ajustes para corregir una venta; siga el procedimiento contable definido por la empresa.
- Si no puede iniciar sesión, compruebe usuario, contraseña y conexión y contacte al administrador.
